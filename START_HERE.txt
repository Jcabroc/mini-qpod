🔌 INTEGRACIÓN ARDUINO:

Necesitas añadir el protocolo serial a test_gait.ino

👉 Lee: INTEGRACION_PASO_A_PASO.md (muy detallado)

Son 5 pasos simples de copiar/pegar:
   1. #include <EEPROM.h>
   2. Copiar struct y funciones EEPROM
   3. Copiar función serial_process()
   4. Añadir eeprom_init() en setup()
   5. Añadir serial_process() en loop()

Tiempo total: 15 minutos

❓ ¿NO FUNCIONA?

1. Si NO instala pyserial:
   python -m pip install pyserial --user

2. Si Arduino no responde:
   - Verifica que esté plugged
   - Abre Monitor Serial de Arduino IDE
   - Baud rate: 115200

3. Si quieres ver qué pasa en Arduino:
   - Monitor Serial → Selecciona puerto → OK
   - Envía comando "INFO"

📞 SOPORTE RÁPIDO:

Problema          | Solución
─────────────────────────────────────
Puerto no aparece | Drivers CH340 + reiniciar
Serial error      | pip install pyserial
GUI no abre       | Necesitas display (no SSH)
Arduino no responde | Verifica serial_process() en loop()
Parámetros no guardan | Usa botón "EEPROM_SAVE"
